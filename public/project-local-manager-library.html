Local Manager Library

Luau · toolkit

Project

A practical toolkit for Roblox workflows.

Local Manager Library is a modular Luau toolkit for Roblox executor environments. It places a consistent API over local file operations, HTTP downloads, HTML-to-GUI conversion, media playback, instance saving, workspace organization, and system diagnostics.

The library is designed to make larger Luau applications easier to build: an app can ask the manager to create a file, fetch a resource, or turn an HTML document into UI without rewriting executor-specific plumbing for every feature.

View source on GitHub

Core modules

What it provides

Files

Safe file workflows

Create, move, delete, and restore workspace files with automatic undo backups. Deleted files can be restored from a matching .undo backup.

Network

Downloads & requests

Wrap GET and POST request flows, custom headers, and resource downloads behind one consistent manager API.

UI

HTML-to-GUI

Translate familiar HTML elements and inline styles into native Roblox GUI objects, including frames, buttons, inputs, labels, images, and scrolling lists.

Media

Audio & video

Provide native Sound playback and experimental VideoFrame support, including folder-level batch audio playback.

Instances

Save and organize

Save raw content as supported Roblox instances and keep generated scripts and assets inside a managed script folder.

Diagnostics

Environment profiling

Inspect executor detection, filesystem access, HTTP support, GUI and Drawing capabilities, and available memory.

Architecture

Designed for inconsistent runtimes

Compatibility layer

The library sits above executor-specific globals such as writefile, request, and Drawing.new. It gives applications a shared interface instead of making every feature handle each runtime separately.

Its target environment expects a Luau runtime with protected calls, isolated file storage, HTTP access, and Roblox GUI or Drawing APIs.

Protected operations

Operations are wrapped in protected calls and return descriptive status messages. That makes failures visible to the calling application while keeping file, network, and UI helpers modular.

The result is a reusable foundation for tools that need persistence, downloads, generated interfaces, and diagnostics in one project.

Getting started

Load the module, then call the manager

These examples show the public API shape. Check the repository for the latest implementation.

Load

Fetch the library

local manager = loadstring(game:HttpGet("https://raw.githubusercontent.com/displaynameroblox/localmaner/main/localmaner.lua"))()
Expected resultmanager → library table loaded

The loader returns the manager table. The library also runs its environment diagnostics during startup.

Files

Create and move content

local result = manager.new("config.json", '{"theme":"neon"}')
print(result)
local moved = manager.move("config.json", "settings/config.json")
print(moved)
Expected outputfile created successfully file moved successfully

new writes content, while move relocates an existing file.

API examples

Common workflows

Undo

Delete safely and restore

local deleted = manager.dfile("config.json", false)
print(deleted)
local restored = manager.dfile("config.json", true, "config.json.undo")
print(restored)
Expected outputfile deleted successfully, undo backup created at: config.json.undo file restored successfully from undo backup

Deletion creates an undo backup; passing true restores it.

Network

Download a resource

local result = manager.download(
  "https://example.com/data.json",
  "data.json",
  "GET"
)
print(result)
Expected outputfile downloaded successfully

The method also accepts POST and an optional headers table. Network failures return a descriptive error string instead.

HTML UI

Convert HTML into GUI

manager.new("panel.html", [[
<div style="background-color: rgb(40, 40, 40); width: 400; height: 300;">
  <h1 style="color: white;">Welcome</h1>
  <button style="color: white;">Open</button>
</div>
]])
local panel = manager.html(nil, true, "panel.html", true)
Expected resultpanel → Roblox GUI instance (Frame)

HTML elements map to Roblox GUI objects such as frames, buttons, inputs, labels, images, and lists.

Diagnostics

Inspect capabilities

local systemInfo = manager.nodefecth()
local capabilities = manager.checkSaveasCapabilities()
print(systemInfo)
print(capabilities.Sound)
Representative outputsystemInfo → capability report table true -- if Sound saving is supported

nodefecth checks executor, filesystem, HTTP, GUI, Drawing, and memory capabilities. The exact table fields depend on the current runtime.
