Displayoptiy

Luau · music player

Project

A personal music experience inside Roblox.

Displayoptiy is a client-side music player designed around a familiar streaming experience. It combines responsive playback controls with playlist management, search, themes, and local settings persistence.

View source on GitHub

Experience

Built for listening

Playback

Full controls

Play, pause, next track, previous track, and configurable volume controls keep listening flexible.

Modes

Shuffle & repeat

Integrated playback modes support continuous listening and make the player feel closer to a full streaming client.

Playlists

Organize music

Create, rename, delete, search, and reorder custom track lists instead of relying on one fixed queue.

Discovery

Home & search

A universal song view, Home tab, and search tools make tracks easier to find across supported games.

Themes

Personal settings

Choose Dark, Light, or Neon themes and customize the visual palette to match your setup.

Persistence

Reliable local storage

Playlists and configuration are saved to local workspace files when available, with in-memory session storage as a fallback when file access is restricted.

Project lifecycle

How Displayoptiy evolved

v0.8

Foundation

The early release fixed initial GUI loading issues and introduced the multi-theme engine with Dark, Light, and Neon options.

v0.9 → v0.9.1

More ways to manage music

These releases added universal song views, persistent playlist and song saving, Search and Home tabs, an Unload setting, and improved GUI rendering stability.

v1.0

Complete public release

The documented v1.0 state includes the full playback suite, responsive UI layout, and playlist search. The public release is marked discontinued, with later active development moved to a closed community beta.

Relationship to the library

A real application built on shared tools

Displayoptiy demonstrates how the Local Manager Library can support a larger client application. Local file helpers handle playlist and configuration persistence, while the UI and media modules provide the building blocks for a responsive music experience.

This separation keeps the player focused on user experience while the library absorbs executor differences and protected file or network operations.
